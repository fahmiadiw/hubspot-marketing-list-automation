# One-click marketing list from a HubSpot export

Turns a raw HubSpot contacts export into a clean, ready-to-send marketing list, with a summary sheet (pie and bar chart), in one run.

## The problem

The marketing team regularly asked for contact lists from our HubSpot CRM. Every request meant the same routine:

1. Agree on the criteria with marketing
2. Enter the filters in the CRM
3. Export the raw file
4. Clean and re-arrange it in Excel, then build a pie and a bar chart by hand
5. Send it, and wait for changes

About **2 hours per request**.

## The fix

We agreed on a standard set of criteria **once** and saved them as defaults in the script. Marketing adds extra filters only when they need them. One run:

- removes duplicate contacts (keeps the most recently active record)
- fixes casing, extra spaces and country spellings (`USA`, `US`, `United States` → `United States`)
- drops contacts with no email or who unsubscribed
- applies the agreed criteria plus any extras
- writes one Excel file: a **Summary** sheet with the charts, and a **Contact List** sheet with filters and frozen headers

**Result: 2 hours → under 1 minute per request.**

## Run it

```bash
pip install -r requirements.txt

# 1. make the sample HubSpot-style export (fake data)
python make_sample_export.py

# 2. the usual request: default criteria only
python make_marketing_list.py sample_hubspot_contacts_export.csv

# 3. extra criteria from marketing
python make_marketing_list.py sample_hubspot_contacts_export.csv --country Canada --title cfo,finance
```

Sample output:

```
Done: 1,620 raw rows -> 1,108 contacts -> marketing_list_20261111.xlsx
Done: 1,620 raw rows -> 144 contacts -> marketing_list_canada_finance.xlsx
```

Optional filters: `--country`, `--industry`, `--title` (keywords), `--stage`, `--out`.

## About the data

Everything here is **made-up sample data** generated by `make_sample_export.py`. The original tool was built for a previous employer's HubSpot CRM. No real client or contact data is included.
